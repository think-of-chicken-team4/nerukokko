## 今後の課題（急がない）

- たまごの省電力処理が未実装（常時 BLE＋マイク＋ADC）。1000mAh で一晩もつか実測する（デザインレビューの課題1）。
- 鶏のマイクは常時ストリームを開いているため、音声会話の録音と同じデバイスを取り合わないように設計する。
- A111 の接続方式（`RADAR_LINK`）は実機で確認する。
- `docs/software-spec.md` 4-2 は「ACK」、`docs/ble-protocol.md` は「Notify のみ」になっていて矛盾している（S4 の対応に合わせて揃える）。
- README の「HTTP REST」は、実際の通信は HTTPS なので表記を揃える。
- GitHub Actions で `pio run` と Python の構文チェックを自動化する（dev-plan T-007）。

## 補足：`backend` ブランチ

`origin/backend`（siratama999、2026-08-08）には `server/` に C++ のサンプル（アラーム開始・停止を表示するだけ）があります。
バックエンドは Supabase（SQL＋Deno/TypeScript の Edge Functions）で作る方針なので、**このブランチは main にマージしない**方がよいです。作成者と相談し、バックエンドの作業は Supabase の構成で進めてもらうよう共有してください。
