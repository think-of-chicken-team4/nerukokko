## 2. 画面の動き

```
[目の画面]（ふだん。昼も夜も表示）
   │ タッチ
   ▼
[メニュー画面] ── 会話（チャット）／（ほかの項目は岡田さんが決める）
   │ 何もしないで一定時間たつ・「戻る」
   ▼
[目の画面]
```

- **目の画面**：まばたき・視線のゆらぎ。鶏の状態に合わせて表情を変える（§3）。
- **夜**：暗い目（暗い色・低い明るさ）にして、睡眠の邪魔にならないようにする。照度センサー（BH1750）の値か時刻で切り替える。
- **メニュー画面**：会話（チャット）など。何も触らなければ、しばらくして目の画面に戻る。
- 会話は、今のトサカボタンと同じ流れ（録音 → `voice-chat` → 返事を再生。`app.py` の `_talk()`）をタッチで始める。画面に会話の文字を出すかどうかは岡田さんが決める。

## 3. 表情の目安（具体的な調整は岡田さん）

| 鶏の状態 | 表情の例 | 本体のどこで分かるか |
|---|---|---|
| アラームが鳴っている | 起こす（WAKE） | `alarm.ringing` |
| 会話で録音している | 聞いている（LISTEN） | `_talk()` の録音中 |
| 返事を待っている | 考え中（THINK） | `_talk()` の送信〜返事 |
| 朝のコメントを話している | うれしい（HAPPY） | `_say()`（`announcements` の `morning_summary`） |
| 記録中（眠っている） | 眠り（SLEEP）・暗い目 | device-sync の `session` が `in_progress` |
| 夕方〜就寝前 | 眠い（SLEEPY） | 時刻、夕方の提案を話したあと |
| それ以外 | 通常（NORMAL） | — |

## 4. 守ること

- **アラームは、画面のタッチでは止めない**。たまごを巣に戻したときだけ止まる（二度寝防止の仕組み。仕様書 §2.4-3）。
- 表示が止まったり落ちたりしても、アラーム・計測・BLE・サーバーへの送信は止まらないようにする（Pi 3B は非力なので、表示の負荷も小さくする）。
- 実機で調整する値（夜の明るさ、照度のしきい値、メニューから戻るまでの時間など）は設定1か所（`integration_config.py`／`chicken.env`）に集め、コメントで「実機で調整」と書く（CLAUDE.md §3-1）。
- 新しいライブラリ（pygame など）は `firmware/chicken/requirements.txt` と README のセットアップ手順に書く。
- 通信の契約（`docs/api-spec.md`）を変える必要が出たら、先に田村さんに相談する。

## 5. 実機で確かめること（`docs/hw-verification.md` D1〜D3）

| ID | 内容 | 合格の目安 |
|---|---|---|
| D1 | 本体（BLE・レーダー・送信）と表示を同時に1時間動かしたときの CPU と温度 | CPU 使用率の合計が 80% 未満。アラーム・BLE の取りこぼしがない |
| D2 | 夜の暗い目が、暗い部屋でまぶしくないか。バックライトの明るさを変えられるか | 暗い部屋で気にならない |
| D3 | 8時間つけっぱなしで落ちないか。タッチ → メニュー → 会話 → 目の画面に戻る、が続けてできるか | 表示が止まらない（止まっても自動で再起動する）。20回続けて操作できる |
