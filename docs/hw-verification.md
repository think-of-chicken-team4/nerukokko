## たまご（ESP32）

### E1. 加速度センサーの接続と寝返りのしきい値 ★（Issue #3）
- 届いた SEN0142 の基板・型番を確認する（部品表では MPU-6050＝I2C だが、今のコードはアナログ3軸として読んでいる）。
- 値を読むだけのテストで、たまごを傾けたとき・置いたままのときの値をシリアルモニタで記録する。
- ベッドの上に置いて実際に寝返りを10回し、検知した回数と比べる。しきい値（`MOTION_THRESHOLD`）を調整する。
- **合格の目安**：寝返り10回中8回以上を検知し、じっとしている5分間の誤検知が1回以下。

### E2. マイクの音量レベル
- 静かな部屋・普通の話し声・いびきの音（スマホで再生）の3つで、Audio Level の値を30秒ずつ記録する。
- **目的**：いびき・寝言を判定するしきい値の材料にする（`docs/api-spec.md` §6-2）。**記録した値を Issue #6 に貼る。**

### E3. 充電検知（巣に戻した判定） ★（Issue #5）
- 巣に置く／取り出すを10回ずつ行い、Dock Event が毎回正しく出るか確認する。
- **満充電の状態で巣に置いたとき**、および**巣の上で満充電になったとき**の STAT ピンの電圧をテスターで測る。
- 「巣に置いたのに検知しない」「置いたままなのに『取り出した』と出る」が起きたら、巣からの 5V を直接検知する回路に変えるかを HW 担当と相談する。
- **合格の目安**：満充電のときも含めて、20回中20回正しく検知する（二度寝防止の要なので妥協しない）。

### E4. BLE 通信の安定性 ★
- 鶏（ラズパイ）を実際の置き場所（ベッド横）に、たまごをベッドの上に置き、30分間データが届き続けるか確認する。
- たまごを布団の下に入れた状態でも届くか確認する。
- 鶏の電源を入れ直す、たまごの電源を入れ直すなどして、自動で再接続されるか確認する。
- **合格の目安**：30分間の取りこぼしが1%以下。再接続が1分以内。

### E5. バッテリーの持ち
- 満充電から、実際の使い方（BLE 送信しながら）で何時間動くかを測る。
- **合格の目安**：9時間以上（一晩＋余裕）。足りなければ、送信間隔を延ばすなどの省電力化を AI に依頼する。

## 鶏（Raspberry Pi 3B）

### C1. ラズパイのセットアップとピン割り当て ★（最初にやる）
- Raspberry Pi OS を入れ、Wi-Fi・SSH・I2C・SPI・I2S を使えるようにする。手順と設定をメモして残す（あとで PR にする）。
- **ピンがぶつからないか確認する**：I2S のマイクとスピーカーアンプ（GPIO18〜21）、LED（WS2812B は GPIO18 がよく使われるが、I2S と重なる）、A111（SPI か USB か）、I2C センサー、ボタン。
- 決まったピン割り当てを表にまとめる（コードの設定値になる）。

### C2. ミリ波レーダー（A111） ★
- A111 モジュールの接続方式（SPI・UART・USB）を確認し、Acconeer の公式ツールで波形が見えることを確認する。
- 実際にベッドで横になり、呼吸数を1分間数えて、レーダーの値と比べる。
- 鶏の置き場所（ベッドからの距離・高さ・向き）を変えて、一番安定する位置を探す。ベッドから離れたときに「不在」になるかも確認する。
- **合格の目安**：自分で数えた呼吸数との差が ±3回/分 以内。

### C3. 温湿度・照度センサー（Issue #4）
- 温湿度センサー M0235-1747 のチップ型番を確認する（AI が読み取りコードを書くのに必要）。
- 市販の温湿度計と並べて、値の差を記録する。照度は明るい部屋と真っ暗な部屋で確認する。

### C4. マイク（SPH0645）
- `arecord` で5秒録音し、再生して声が聞き取れるか確認する。
- ベッドから話しかける距離で録音し、音量が小さすぎないか確認する（音声会話の聞き取りに使うため）。

### C5. スピーカー ★
- `aplay` でテスト音（コケコッコー）を鳴らす。
- 寝ている人が起きられる音量か、夜中にうるさすぎないかを確認し、ちょうどよい音量を決める。

### C6. LED（WS2812B）
- 点灯・色の変化・明るさの変化を確認する。
- 光アラームとして目が覚める明るさか、暗い部屋でまぶしすぎないかを確認する。

### C7. トサカボタン
- 押したときに1回だけ反応するか（チャタリングがないか）確認する。

### C8. Wi-Fi 経由のサーバー送信
- 鶏から送ったデータが Webアプリに表示されるか確認する。
- 途中で Wi-Fi を切り、つなぎ直したときに、たまっていたデータが送られるか確認する。

## 結合テスト

### I1. 起床シーケンス ★
- アラームを数分後にセット → 鳴る → たまごを巣に戻す → 止まる、を**10回連続**で行う。
- たまごと鶏の BLE を切った状態でも止まるか（予備経路）を確認する。
- **合格の目安**：10回中10回止まり、巣に戻してから止まるまで3秒以内。

### I2. 一晩の通し計測 ★
- 実際に一晩使い、朝に Webアプリでグラフ・スコアが表示されるか確認する。
- スコアと、自分の「よく眠れた／眠れなかった」という感覚を比べて記録する（1週間続けられるとよい）。

### I3. 音声会話の通し
- ボタンを押して話しかけ、返事が再生されるまでの時間を10回測る。
- **目標**：3〜5秒。聞き取りの失敗が何回あったかも記録する。

### I4. 寝返り・いびき・寝言の検知精度
- 一晩の様子をスマホで録音・録画（本人の同意のうえで）しておき、検知されたイベントと照らし合わせる。
- 見逃し・誤検知の回数を記録し、しきい値の調整に使う。
